B. The Netlify side

Where this lives.

Plain words first, then the exact Netlify name or call in code type.

The website and the portal

Run on Netlify, in the project chemtecpro.

Netlify project: chemtecpro
Where logins are kept

A private Netlify Blobs store called portal-users. One record per login, filed under the account number (an admin under their username), in lowercase.

getStore({ name: "portal-users", consistency: "strong" })
store portal-users, key = account number in lowercase, for example 0001
Passwords

Kept only as a scrambled one way hash. Nobody can read a password back, not even on this page.

node:crypto scrypt (N=32768, r=8, p=1), random 16 byte salt, field passwordHash
Login emails

The Chemtec branded login email. The site sends it through Resend only when automatic email is set up (RESEND_API_KEY) and you tick Email the login now or press Send; otherwise you copy it into your own email. The temporary password goes into that one email and is never kept. Up to 30 sends an hour per admin.

netlify/lib/email-templates.mjs (the email) and netlify/lib/mailer.mjs (the send)
POST https://api.resend.com/emails, Authorization: Bearer <RESEND_API_KEY>
from PORTAL_FROM, reply_to PORTAL_REPLY_TO
store portal-mail, key sends-<admin username> (send times only)
Staying logged in

A signed cookie that lasts 8 hours. Turning a login off, resetting it or deleting it ends its sessions at once. 10 wrong passwords lock that login for 15 minutes.

cookie __Host-chemtec_session, HMAC SHA-256 signed with SESSION_SECRET; HttpOnly, Secure, SameSite=Lax, Path=/

Netlify Functions, each at its own address on the site.

The gate in front of the documents

A Netlify Edge Function checks the login before any PDF, the old documents page or this admin page is served. No login, no file.

netlify/edge-functions/portal-gate.mjs, path /* (only the site's own styles, scripts, images and video in /assets/ skip it; nothing in /assets/docs/ does)
Settings

Netlify environment variables, in the Netlify project under Project configuration, Environment variables. Only the names are shown here, never the values.
